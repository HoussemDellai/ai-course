## Quick takeaways

The biggest themes across Microsoft, Google, AWS, Anthropic, and OpenAI are:

- **Enterprise AI agents are becoming platforms, not just demos**
- **Multi-agent orchestration** is now a core product area
- **Protocols and interoperability** are becoming strategic:
  - MCP / Model Context Protocol
  - A2A / Agent-to-Agent
- **Security and governance for agents** are now first-class concerns
- **Cloud distribution is shifting**, especially around OpenAI, Microsoft, AWS, and Google
- **Coding, browser/computer use, workflow automation, and cybersecurity** are the main agent battlegrounds

# Latest updates by company

## Microsoft

### 1. Microsoft is pushing “Agent 365” as a control plane for agents
From Microsoft Ignite 2025 Book of News:

- **Microsoft Agent 365** is positioned as the management/governance layer for enterprise agents
- Includes:
  - **registry of agents**
  - **access control**
  - **visualization**
  - **interoperability**
  - **security**
- Integrated with:
  - **Microsoft Defender**
  - **Microsoft Entra**
  - **Microsoft Purview**
  - **Microsoft 365 admin center**

This is one of the clearest signals that Microsoft sees AI agents as a managed workforce layer inside the enterprise.

### 2. Microsoft launched multiple business agents
Microsoft announced several specialized agents, including:

- **Sales Development Agent**
- **Workforce Insights Agent**
- **People Agent**
- **Learning Agent**
- **Teams Admin Agent**
- **SharePoint Admin Agent**
- Word / Excel / PowerPoint agents inside Microsoft 365 Copilot

### 3. Agents in Teams can connect to third-party tools via MCP
In preview:

- Teams channel agents can work with **GitHub, Asana, Jira** and other third-party apps
- Enabled via **Model Context Protocol (MCP)**

This is important because Microsoft is not just building closed internal agents; it is embracing agent/tool interoperability.

### 4. Microsoft Foundry is becoming a major agent platform
Microsoft announced updates to **Microsoft Foundry** and **Foundry Agent Service**:

- hosted agents
- built-in memory
- multi-agent workflows
- unified MCP tools catalog
- model router
- control plane for observability and governance

This looks like Microsoft’s answer to agent runtime + orchestration + enterprise operations.

### 5. Azure Copilot is evolving into a specialized agent system
Private preview updates show Azure Copilot gaining agentic capabilities for:

- deployment
- migration
- optimization
- observability
- resiliency
- troubleshooting

### 6. Microsoft is heavily focused on agent security
Major agent-security announcements include:

- **Defender unified posture management and threat protection for AI agents**
- **Entra Agent ID** for agent identity
- **Purview protections for agents**
- **Security Copilot agents**
- **Security Dashboard for AI**

### 7. Microsoft and OpenAI restructured their partnership
From The New Stack and other coverage:

- OpenAI is no longer effectively limited to Azure-only distribution
- This opens room for OpenAI on **AWS** and **Google Cloud**
- Microsoft is simultaneously broadening its own model/platform strategy

That is one of the most important market-structure changes around AI agents.
